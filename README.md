# Salnet86 Database Projects

Benvenuti nella repository **Salnet86 Database Projects**!  
Questa raccolta contiene vari progetti e script relativi a database, inclusi esempi di applicazioni web, gestione di database MySQL e script SQL.

## 📂 Struttura dei progetti

### 1. Flask con MySQL
- **Descrizione**: Applicazione web di esempio utilizzando Flask e MySQL.
- **File**: `Flask_Insert_Delete_SQL`
- **Tecnologie**: Python, Flask, MySQL
- **Istruzioni**: Estrai il contenuto del file ZIP e importa il progetto in un IDE Python.

### 2. Hibernate con Java
- **Descrizione**: Esempio di utilizzo di Hibernate con Java per la gestione di database.
- **File**: `HibernateExample`
- **Tecnologie**: Java, Hibernate
- **Istruzioni**: Estrai il contenuto del file ZIP e importa il progetto in un IDE Java.

### 3. Script SQL Vari
- **Descrizione**: Una raccolta di script SQL per vari scopi.
- **File**: `AmministratorMysql.sql`, `CalcoloSaldoSubQuery.sql`, `DataBaseDipendenti.sql`
- **Tecnologie**: SQL
- **Istruzioni**: Esegui gli script nel tuo ambiente MySQL.

## ⚙️ Tecnologie utilizzate
- Python
- Flask
- Java
- Hibernate
- MySQL
- SQL

## 📌 Note
- Ogni progetto potrebbe avere requisiti specifici; leggere il README interno se presente.
- Alcuni file `.zip` contengono progetti completi; consigliato estrarli in cartelle dedicate.

Se non riesci ad accedere a MySQL con il comando mysql -u root -p, probabilmente MySQL sta utilizzando l'autenticazione tramite il plugin auth_socket, che non consente l'accesso tramite password per l'utente root.


Puoi risolvere questo problema ripristinando l'accesso tramite password. Segui questi passaggi per reimpostare la configurazione di MySQL e consentire l'accesso con la password per l'utente root


sudo mysql


ALTER USER 'root'@'localhost' IDENTIFIED WITH mysql_native_password BY '';






FLUSH PRIVILEGES;





exit;
